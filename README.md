# KovaltKeySystem 🗝️

Профессиональная система замков и ключей для серверов Minecraft (Paper/Spigot 1.21+). 
Плагин позволяет игрокам защищать свои дома, создавать уникальные ключи и объединять их в связки.

## ✨ Основные возможности
* **Умные замки:** Возможность запереть любую дверь или люк. Система автоматически распознает двойные (высокие) двери.
* **Привязка ключей:** Создавайте "Ключи-пустышки" и привязывайте их к своим замкам прямо на месте.
* **Система дубликатов:** Только владелец замка может создавать копии ключей.
* **Связка ключей (Keychain):** Объединяйте до бесконечного количества ключей в одну цепь, чтобы не занимать место в инвентаре.
* **Безопасность:** Защита от случайной постановки ключей как блоков и полная синхронизация инвентаря.
* **Вечное хранение:** Все данные о владельцах и замках сохраняются в `data.yml` и не пропадают после перезагрузки.

## 🛠️ Крафты
* **Замок:** Медь + Золото + Алмаз (Схема: Кольцо из меди, золото по бокам, алмаз в центре).
* **Ключ-пустышка:** Медь + Золото + Медь (Вертикальная линия).
* **Связка ключей:** Ромб из цепей с медным слитком в центре.
