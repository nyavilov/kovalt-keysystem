# KovaltKeySystem 🗝️

Профессиональная система замков и ключей для серверов Minecraft (Paper 1.21.11). 
Плагин позволяет игрокам защищать свои дома, создавать уникальные ключи и объединять их в связки.

## ✨ Основные возможности
* **Умные замки:** Возможность запереть любую дверь или люк.
* **Привязка ключей:** Создавайте "Ключи-пустышки" и привязывайте их к своим замкам прямо на месте.
* **Система дубликатов:** Только владелец замка может создавать копии ключей.
* **Связка ключей:** Объединяйте до бесконечного количества ключей в одну цепь, чтобы не занимать место в инвентаре.
* **Вечное хранение:** Все данные о владельцах и замках сохраняются в `data.yml` и не пропадают после перезагрузки.

## 🛠️ Крафты
* **Замок:** Медь + Золото + Алмаз (Схема: Кольцо из меди, золото по бокам, алмаз в центре).
* **Ключ-пустышка:** Медь + Золото + Медь (Вертикальная линия).
* **Связка ключей:** Ромб из цепей с медным слитком в центре.

## 📦 Сборка проекта

Для компиляции плагина вам понадобится установленный **Java JDK 21** и **Maven**.

1. **Клонируйте репозиторий:**
   ```
   git clone https://github.com/твой_ник/KovaltKeySystem.git
   cd KovaltKeySystem
   ```

2. **Запустите сборку:**
   ```
   mvn clean package
   ```

3. **Заберите готовый файл:**

После успешной сборки (BUILD SUCCESS), скомпилированный плагин появится в папке target/ под названием KovaltKeySystem-1.0-SNAPSHOT.jar.
